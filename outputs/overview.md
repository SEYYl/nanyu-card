# UI 设计系统方案总结

## 项目概述

为 Nanyu Card 个人主页项目创建了一套完整的 UI 设计系统方案，旨在提供统一、美观、易用的用户界面规范。

## 设计目标

1. **一致性** - 所有界面元素遵循统一的设计语言
2. **可用性** - 界面直观易用，符合用户习惯
3. **美观性** - 现代深色主题，视觉层次清晰
4. **响应式** - 适配桌面、平板、手机等多种设备
5. **无障碍** - 符合 WCAG AA 标准，支持键盘导航和屏幕阅读器

## 设计系统架构

### 1. 设计基础层

#### 颜色系统
- **主色调**: 蓝色系 (#378ADD) - 用于主要按钮、链接、强调元素
- **辅助色**: 紫色系 (#7F77DD) - 用于次要元素、装饰
- **语义色**: 成功(绿色)、警告(琥珀色)、错误(红色)、信息(蓝色)
- **中性色**: 灰色系 - 用于文本、边框、背景

#### 字体系统
- **主字体**: Inter, system-ui, -apple-system, sans-serif
- **中文支持**: PingFang SC, Hiragino Sans GB, Microsoft YaHei
- **等宽字体**: SF Mono, Monaco, monospace
- **字体权重**: 400 (常规), 500 (中等)

#### 间距系统
基于 8px 网格系统：4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px

#### 圆角系统
- 小圆角: 6px - 按钮、标签
- 中圆角: 8px - 输入框、卡片
- 大圆角: 12px - 模态框、大卡片
- 超大圆角: 16px - 特殊元素

### 2. 组件层

#### 基础组件
1. **按钮 (Button)**
   - 变体: 主要、次要、幽灵
   - 尺寸: 小、中、大
   - 状态: 正常、悬停、聚焦、禁用、加载

2. **输入框 (Input)**
   - 类型: 文本、密码、搜索
   - 状态: 默认、聚焦、错误、禁用

3. **选择器 (Select)**
   - 单选、多选
   - 下拉菜单

4. **开关 (Switch)**
   - 开/关状态
   - 禁用状态

#### 复合组件
1. **卡片 (Card)**
   - 布局: 基础、带图片、操作卡片
   - 状态: 默认、悬停、选中

2. **标签 (Tag)**
   - 颜色变体: 蓝色、紫色、绿色、红色、琥珀色
   - 尺寸: 小、中

3. **徽章 (Badge)**
   - 数字徽章
   - 状态徽章

4. **提示 (Tooltip)**
   - 位置: 上、下、左、右

#### 布局组件
1. **导航栏 (Navbar)**
   - 固定顶部
   - 响应式折叠

2. **侧边栏 (Sidebar)**
   - 固定左侧
   - 可折叠

3. **页脚 (Footer)**
   - 固定底部
   - 响应式布局

4. **网格 (Grid)**
   - 12 列网格系统
   - 响应式断点

### 3. 页面层

#### 首页布局
- 导航栏 → 个人介绍 + 统计数据 → 项目展示 → 技能展示 + 经历时间线 → 页脚

#### 项目页布局
- 导航栏 → 筛选器 + 项目网格 → 分页组件

#### 管理后台布局
- 顶部栏 → 侧边栏 + 内容区（表单区域 + 操作区域 + 预览区域）

## 响应式设计

### 断点系统
- **手机**: < 640px
- **平板**: 640px - 1024px
- **桌面**: > 1024px

### 布局适配
- **导航栏**: 桌面显示完整链接，平板/手机折叠为汉堡菜单
- **项目网格**: 桌面3列 → 平板2列 → 手机1列
- **侧边栏**: 桌面固定显示，平板/手机可折叠

## 无障碍标准

### WCAG AA 合规
- **颜色对比度**: 4.5:1 (正常文本), 3:1 (大文本)
- **键盘导航**: 所有交互元素支持键盘操作
- **屏幕阅读器**: 语义化 HTML 和 ARIA 标签
- **焦点管理**: 清晰的焦点指示器和逻辑标签顺序

### 包容性设计
- **触摸目标**: 最小 44px × 44px
- **运动敏感**: 尊重用户减少动画的偏好
- **文本缩放**: 支持浏览器文本缩放至 200%
- **错误预防**: 清晰的标签、说明和验证

## 性能优化

### 图片优化
- 使用 WebP 格式
- 响应式图片 (srcset)
- 懒加载

### CSS 优化
- 使用 CSS 变量
- 避免复杂选择器
- 使用 CSS containment

### JavaScript 优化
- 组件懒加载
- 虚拟滚动
- 事件委托

## 开发规范

### 文件结构
```
src/
├── components/          # 组件目录
│   ├── base/           # 基础组件
│   ├── composite/      # 复合组件
│   └── layout/         # 布局组件
├── styles/             # 样式目录
│   ├── variables.css   # CSS 变量
│   ├── base.css        # 基础样式
│   └── components/     # 组件样式
├── composables/        # 组合式函数
├── utils/              # 工具函数
└── types/              # TypeScript 类型
```

### 命名规范
- **组件**: PascalCase (如 `NavBar.vue`)
- **文件**: kebab-case (如 `nav-bar.css`)
- **CSS 类**: kebab-case (如 `nav-bar__link`)
- **变量**: camelCase (如 `primaryColor`)

### 样式规范
- 使用 CSS 变量定义设计令牌
- 使用 scoped 样式避免冲突
- 遵循 BEM 命名规范
- 保持样式单一职责
