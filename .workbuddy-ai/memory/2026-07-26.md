## 踩到的坑

**Vite 8 构建 EISDIR**：`<link rel="canonical" href="/" />` 这种以 `/` 结尾的绝对路径会让 vite 在 `processAssetUrl` 时去解析为静态资源，最终触发 EISDIR。修法：去掉 canonical 标签，或换成带文件名的 URL。

**JSON DB 字段迁移**：当 `loadState` 读到老数据时，要先 spread default 再做字段归一化，否则新字段会缺失。`normalizeStringArray` 同时支持数组和「、, 逗号分隔字符串」，方便后台表单输入。

**Session secure Cookie 与 HTTP**：生产环境必须 HTTPS，否则浏览器拒绝带 `secure` 的 Cookie → 后台一直「请先登录」。Nginx 反代要带 `X-Forwarded-Proto`；如跨域再考虑 `trust proxy`。

## 样式问题修复

### 问题：排版乱了 + 登录按钮不可见
**根因**：
1. `--space-5`、`--space-7`、`--space-9` 三个间距变量未定义 → CSS 回退为 0，导致各 section 的 padding/margin 全部塌缩，排版崩溃
2. `button.secondary` 误用了浅色主题令牌 `--color-text-primary`（#1a1a1a）+ `--color-border-secondary`（rgba(0,0,0,0.3)），在深色背景上完全不可见 → "没有登入按键"

**修复**：
1. 补全间距变量：`--space-5: 20px`、`--space-7: 28px`、`--space-9: 36px`
2. 按钮、pill、badge 回退到深色主题兼容变量（`var(--text-primary)`、`var(--accent)`、`var(--gradient)` 等），保持原有视觉效果
3. 构建验证通过

**教训**：设计令牌整合到已有深色主题项目时，必须保持原有变量的语义层不变；新令牌仅供浅色主题 / `[data-theme="dark"]` 切换使用，日常样式仍走兼容变量。

### 实施效果
1. **一致性提升** - 所有组件使用统一的设计令牌
2. **可维护性增强** - CSS 变量便于主题切换和样式调整
3. **响应式优化** - 更好的移动端体验
4. **无障碍改进** - 符合 WCAG AA 标准
5. **性能优化** - 减少 CSS 重复，提高加载速度
